= Skydive.uz
Сайт Федерации парашютного спорта Узбекистана

Сайт-визитка федерации: главная, о федерации, новости, галерея (живая лента
Instagram), контакты.

== Стек

* Next.js 14 — App Router, TypeScript, Server Components
* Tailwind CSS
* Без базы данных — весь контент статический, живёт в `lib/data.ts`
* Галерея — официальные embed-виджеты Instagram (`instagram.com/embed.js`),
  без бэкенда и токенов

== Структура

[source]
----
app/
  page.tsx                # Главная
  about/page.tsx           # О федерации
  news/page.tsx            # Список новостей
  news/[slug]/page.tsx      # Отдельная новость
  gallery/page.tsx          # Галерея (Instagram embed)
  contacts/page.tsx        # Контакты
  icon.png                 # Favicon (логотип федерации)

components/
  header.tsx / footer.tsx
  page-hero.tsx            # Баннер внутренних страниц
  news-card.tsx
  instagram-embed.tsx      # Обёртка над Instagram embed.js

lib/
  data.ts                  # Весь контент сайта: новости, руководство,
                            # дисциплины, контакты, ссылки на посты Instagram

public/
  logo.png                 # Логотип федерации
----

== Обновление контента

Весь текстовый контент (новости, руководство, статистика, контакты)
редактируется в `lib/data.ts` — отдельного редактора/CMS нет.

=== Галерея

Галерея показывает живые посты из Instagram через официальный embed-виджет.
Чтобы добавить пост:

1. В Instagram: *Поделиться* → *Скопировать ссылку* на нужном посте/reel.
2. Добавить ссылку в массив `instagramPosts` в `lib/data.ts`.

NOTE: Не каждый пост можно встроить — Instagram иногда отказывает
в embed (например, из-за лицензионного аудио). Перед добавлением стоит
проверить ссылку — если карточка не рендерится, потребуется другая ссылка.

Текущий подход — ручное обновление списка ссылок, без автообновления.
Если понадобится живая автообновляемая лента, следующий шаг —
Vercel Cron Job + Instagram Graph API (Instagram Login) + Vercel Blob
для хранения токена и кэша ленты.

== Деплой

Статический Next.js-сайт без БД — подходит любой хостинг с поддержкой
Next.js (Vercel и т. п.).
